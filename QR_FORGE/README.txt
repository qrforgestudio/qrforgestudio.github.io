index.html
qr.generator.html

a.html
b.html

JS:
js/a.js = QR Generator
js/b.js = Resize
js/c.js = Crop
js/d.js = Convert
js/e.js = Compress
js/f.js = Image Editor
js/g.js = Remove Background
js/h.js = reserved
js/common.js = shared functions

Open index.html first.
Run with VS Code Live Server if possible.

Note:
QR generation uses the QRCode.js CDN, so QR generation needs internet access.
Image tools run in the browser.
